# dbd-2558 — พจนานุกรมข้อมูลจริง

ข้อมูลจริง "นิติบุคคลที่จดทะเบียนจัดตั้งใหม่ ประจำปี พ.ศ. 2558" ของ**กรมพัฒนาธุรกิจการค้า** ดาวน์โหลดจากพอร์ทัลข้อมูลเปิดภาครัฐ [data.go.th](https://data.go.th) (รายเดือน: มกราคม กุมภาพันธ์ และมิถุนายน 2558) รวม **16,781 แถวดิบ**

- `data/raw/dbd-2558.parquet` — ข้อมูลดิบต้นทาง (Parquet) แปลงจาก CSV ของ data.go.th (เดิมเข้ารหัส TIS-620) คอลัมน์ชื่อ `*_raw` เก็บค่าตามต้นฉบับ
- `data/warehouse.duckdb` — ฐาน DuckDB ที่มี view `businesses_raw` ที่ชี้ parquet ดิบ — MCP `data-duckdb` ใน `.mcp.json` ใช้ไฟล์นี้ (read-only)
- `data/dataset.csv` — ตารางแบนที่แอปอ่าน (ชุดเริ่มต้นคือสำเนาดิบ: แถวหัวตารางปน วันที่ พ.ศ. ทุนมีลูกน้ำ) การทำความสะอาดจะเขียนทับไฟล์นี้

## คอลัมน์ของ data/dataset.csv (สัญญาของตารางสะอาด)

| คอลัมน์ | ความหมาย | ค่าที่สะอาดแล้วต้องได้ |
|---|---|---|
| `month` | เดือนที่มาจากไฟล์ต้นทาง | `jan` / `feb` / `jun` |
| `seq` | ลำดับแถวในไฟล์ต้นทาง | จำนวนเต็ม ≥ 1 (ต้นฉบับบางส่วนมีลูกน้ำ เช่น `1,000`) |
| `reg_no` | เลขทะเบียนนิติบุคคล | ตัวเลข 13 หลัก ไม่ซ้ำ |
| `company_name` | ชื่อนิติบุคคล | ไม่ว่าง |
| `reg_date` | วันที่จดทะเบียน | `YYYY-MM-DD` คริสต์ศักราช (ต้นฉบับเป็น พ.ศ. เช่น `12/1/2558` = 2015-01-12) |
| `capital` | ทุนจดทะเบียน (บาท) | ตัวเลข ≥ 0 ไม่มีลูกน้ำ/ช่องว่าง (ต้นฉบับเช่น `" 2,000,000,000 "`) |
| `objective` | รายละเอียดวัตถุประสงค์ของนิติบุคคล | ไม่ว่าง |
| `address` | ที่ตั้งสำนักงานใหญ่ | ข้อความที่ต้องระบุจังหวัดที่ตรวจจับได้ |

## คอลัมน์ใน Parquet ดิบ (`*_raw`)

`month, seq_raw, reg_no, company_name, reg_date_raw, capital_raw, objective, address` — ค่าเป็น VARCHAR ตามต้นฉบับทั้งหมด

## กฎคุณภาพ (ตัวตรวจชุดเดียวกับ quality gate)

อ่านได้ที่ `lib/inspect-data.js` — สรุป: seq เป็นจำนวนเต็ม, reg_no 13 หลักไม่ซ้ำ, ชื่อ/วัตถุประสงค์ไม่ว่าง, reg_date เป็น ISO ค.ศ., capital เป็นตัวเลข ≥ 0, และที่อยู่ต้องชี้จังหวัดได้ (ตาราง 77 จังหวัด + ภาค อยู่ในไฟล์เดียวกัน)
